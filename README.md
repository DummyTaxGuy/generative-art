# Bloom — Generative Art Toy

An interactive generative art toy that creates beautiful particle effects in your browser. Click and drag to bloom.

## Features

- **5 color palettes** — Aurora, Sunset, Ocean, Neon, Pastel
- **4 particle shapes** — Circles, Rings, Stars, Petals
- **Touch support** — works on mobile devices
- **Save as PNG** — export your creations

## Usage

Open `index.html` in any modern browser. Click and drag on the canvas to create particle blooms. Use the toolbar at the bottom to change palettes, shapes, clear the canvas, or save your art.
